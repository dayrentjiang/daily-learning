## Lessons

For each lesson record:
- Local date, number, title and objective.
- Status: planned / researching / delivered / partial / blocked.
- Source URLs, access date, evidence actually inspected and relevant timestamps.
- Brief original concept notes (not a copied transcript).
- Chat/PDF/notes locations and checks performed.
- Proposed exercise and completion criterion.
- Learner status: read unknown; comprehension unknown; implementation not reported.
- User-reported attempts, answers and results, with date.
- Review question and suggested review date.

## Transcript attempts

Record each reservation before dispatch when writable storage exists:
- Local date and track.
- Video URL and mode (`native` only).
- Attempt number (maximum two that day).
- State: reserved / succeeded / failed / unknown.
- Job identifier and status checks, if returned.

A failed or uncertain request still counts as an attempt. If the ledger cannot be recovered, use a written source for that run.
