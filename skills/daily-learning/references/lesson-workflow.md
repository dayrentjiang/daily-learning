# Produce a daily lesson

## Choose the skill

Read the learner profile, recent lessons, unresolved questions and reported exercise results. Check today's local date and track: reuse an already delivered lesson rather than generating a duplicate. If a previous run left an artifact but no completed record, inspect it and reconcile the record first.

Choose one next concept from the learning path or a prerequisite revealed by feedback. The output is a coherent lesson, not a summary of whichever video happens to be newest. Every seventh lesson is a new applied case with review. Include brief recall of earlier concepts when useful, roughly after two days, one week and three weeks. Silence is not mastery.

## Research

Search for the chosen objective. Shortlist a few candidates using relevance, author expertise, specificity, evidence, commercial incentives and fit to the learner's level. Assess depth from the actual content before selecting a source. Recent sources matter for changing facts; enduring ideas can use older material.

Usually one strong primary source plus one verification source is sufficient. Retrieve YouTube captions according to [the Supadata policy](supadata.md). Native caption retrieval is not new audio transcription. For a written source, open the full relevant page. A snippet or description alone is insufficient evidence for an episode's teachings.

When accessible, audience comments can reveal specific applications and criticism. Treat claimed credentials as self-reported. If comments cannot be inspected, say nothing about audience reception. Do not call a source a hidden gem merely because it has few views.

Check central factual, numerical and current claims against appropriate authoritative material. Identify opinion, anecdote, uncertainty and disagreement. If only part of a long source was inspected, state the sections reviewed. Keep source statements, your synthesis and proposed applications distinguishable.

Record why the chosen source is useful. If no adequate research source is accessible, report the limitation and offer a clearly labelled general-knowledge exercise; do not fabricate a researched lesson.

## Teach and practise

Default to a five-minute brief of roughly 500–800 words; adapt to the learner's requested time. Use [the lesson template](../assets/lesson.md):

- One objective: what the learner should be able to explain or do.
- A plain-English explanation and two or three connected takeaways.
- One worked example appropriate to their context; label invented details.
- A small exercise with an observable completion criterion. Allocate practice time separately from reading time.
- One or two common mistakes and limits of the method.
- Two recall questions, with answers separated so the learner can try first.
- Source links, checked timestamps where available, and a brief evidence note.

Keep exercises proportionate to available tools, authority and time. Build on an in-progress project rather than accumulating unrelated tasks. Track suggested, attempted and completed work separately.

## Deliver and record

Provide a readable chat version for phone use. If file generation is available, produce a matching one- or two-page PDF with comfortable text and clickable sources; extend the page count rather than shrinking text to fit. Inspect rendered pages where tools allow and check text, calculations and links. Report any check you could not perform. An actual generated artifact is required before sharing a PDF link.

Use `YYYY-MM-DD-lesson-NNN-topic.pdf` for the PDF and preserve editable original notes in accessible user-owned storage. Keep personal data out of the public source repo. If PDF generation fails, deliver the full chat lesson and mark the run partially complete so the artifact can be repaired without re-researching.

Update the learning log with date, objective, source evidence, output location, transcript attempts, proposed exercise and review prompt. Add user-reported feedback without inferring results. Finish with one optional question whose answer would improve the next lesson.
